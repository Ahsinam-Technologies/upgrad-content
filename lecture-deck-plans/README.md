# Lecture Deck Slide-by-Slide Plans

This directory contains intermediate, granular **slide-by-slide plans** for all lecture decks across the 13 modules (M00 to M12).

## Purpose
- Bridge the high-level pedagogical **Learning Journeys** in `curriculum-and-session-plans/` with the final LaTeX/Beamer decks in `lecture-decks/`.
- Plan slide counts, slide titles, visual layout archetypes (comparisons, diagrams, code side-by-side), hooks, speaker notes, and interactive prompts.

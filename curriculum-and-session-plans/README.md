# Curriculum & Session Plans Repository

This directory contains the central course architecture, master curriculum overview, and module-level 4-session plans with detailed learning outcomes.

## Contents
* **Master Curriculum Overview:** [`master_curriculum_overview.md`](./master_curriculum_overview.md)
* **Module Session Plans (M00 to M12):** 13 module-level planning documents defining the 4 sessions per module, prerequisite knowledge, and measurable learning outcomes.

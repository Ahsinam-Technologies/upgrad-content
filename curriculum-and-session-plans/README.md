# Curriculum & Session Plans Repository

This directory contains the central course architecture, master curriculum overview, and module-level session directories with standalone session learning plans.

## Contents
* **Master Curriculum Overview:** [`master_curriculum_overview.md`](./master_curriculum_overview.md)
* **Module Directories (M00 to M12):** 13 module folders, each containing a module overview (`README.md`) and 4 independent session plan documents (`session_01.md` to `session_04.md`).

## Directory Layout
```
curriculum-and-session-plans/
├── README.md
├── master_curriculum_overview.md
├── M00/
│   ├── README.md
│   ├── session_01.md
│   ├── session_02.md
│   ├── session_03.md
│   └── session_04.md
├── M01/
│   ├── README.md
│   ├── session_01.md
│   └── ...
├── M02/ ... M12/
```

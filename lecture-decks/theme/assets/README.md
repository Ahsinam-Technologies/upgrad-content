# Shared assets

Put only assets reusable across more than one deck here (for example, an approved
brand lockup or common icon set). Keep session-specific screenshots, charts and
source-code snippets beside the deck in that deck's `assets/` directory.

The theme uses the official upGrad wordmark red (`#EE2F3D`). No logo or visual
reference was present in the repository at the time of migration; add an approved
vector/PDF logo here if one is supplied by the brand team.

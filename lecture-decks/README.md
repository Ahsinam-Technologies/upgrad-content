# Lecture Decks & Pre-Reads Repository

This directory contains all lecture decks and pre-read materials organized into modular session subfolders.

## Summary Overview
* **Foundations Pre-Module (M00):** 4 Session subfolders (`session-01` to `session-04`). *No pre-read.*
* **Learning Modules (M01 to M11):** 11 Modules, each containing:
  * `pre-read/` (Pre-reading guide for the module)
  * `session-01/` (Lecture slides & artifacts for Session 1)
  * `session-02/` (Lecture slides & artifacts for Session 2)
  * `session-03/` (Lecture slides & artifacts for Session 3)
  * `session-04/` (Lecture slides & artifacts for Session 4)
* **Capstone Module (M12):** *Treated separately in `capstone-project/`*
* **Total Lecture Decks:** **48 Decks**
* **Total Module Pre-Reads:** **11 Pre-Reads** (in `lecture-decks/M01..M11`) + **1 Capstone Pre-Read** (in `capstone-project/`)

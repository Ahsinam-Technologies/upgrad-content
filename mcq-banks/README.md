# MCQ Question Banks Repository

This directory contains all multiple-choice question (MCQ) assessment sets and answer keys across all 13 modules of the Data Science on AWS course, structured into dedicated subfolders per assessment set.

## Assessment Cadence & Subfolder Organization per Module
Each module (`M00` to `M12`) contains **2 subfolders**:
* **`mcq-set-01/`**: Checkpoint assessment evaluating concepts from **Sessions 1 & 2**.
* **`mcq-set-02/`**: Module summative assessment evaluating **Sessions 1 to 4** (with deeper emphasis on **Sessions 3 & 4**).

## Summary
* **Foundations Pre-Module (M00):** 2 MCQ Sets (`mcq-banks/M00/mcq-set-01/` & `mcq-set-02/`)
* **Learning Modules (M01 to M11):** 22 MCQ Sets (`mcq-banks/M01/` to `M11/`)
* **Capstone Module (M12):** 2 Capstone MCQ Sets (`mcq-banks/M12/mcq-set-01/` & `mcq-set-02/`)
* **Total Question Banks:** **26 MCQ Sets**

# Hands-on Code Labs Repository

This directory contains all module-level practical hands-on labs, guided notebooks, and starter code projects for the 11 core learning modules (M01 to M11).

## Overview
* **Foundations Pre-Module (M00):** *No hands-on lab*
* **Core Learning Modules (M01 to M11):** 11 Module Labs (`code-labs/M01/` to `code-labs/M11/`)
* **Capstone Module (M12):** *Treated separately in the dedicated `capstone-project/` directory*
* **Total Code Labs:** **11 Labs**

# Coding Practice Assignments Repository

This directory contains all learner practice coding assignments across all 13 modules of the Data Science on AWS course, structured into dedicated subfolders per assignment.

## Cadence & Subfolder Organization per Module
Each module (`M00` to `M12`) contains **2 subfolders**:
* **`assignment-01/`**: Focuses on practical coding exercises based on **Sessions 1 & 2**.
* **`assignment-02/`**: Comprehensive coding exercises covering **Sessions 1 to 4** (with deeper emphasis on **Sessions 3 & 4**).

## Summary
* **Foundations Pre-Module (M00):** 2 Assignments (`coding-assignments/M00/assignment-01/` & `assignment-02/`)
* **Learning Modules (M01 to M11):** 22 Assignments (`coding-assignments/M01/` to `M11/`)
* **Capstone Module (M12):** 2 Capstone Milestones (`coding-assignments/M12/assignment-01/` & `assignment-02/`)
* **Total Assignments:** **26 Practice Assignments**
